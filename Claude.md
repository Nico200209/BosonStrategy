# Project Context

This project is a professional corporate website for:

Bosón Ingeniería Estratégica de Negocios

The project already exists and MUST NOT be rebuilt from scratch.

The current stack:
- Next.js App Router
- React
- TypeScript
- Tailwind CSS

The current architecture is component-driven and should be preserved whenever possible.

Primary priorities:
1. SEO
2. Performance
3. Brand consistency
4. cPanel compatibility
5. Clean maintainable structure

Important rules:
- Preserve reusable UI components
- Do not unnecessarily rewrite sections
- Keep animations lightweight
- Maintain responsive design
- Keep the site static-first
- Avoid server-heavy dependencies
- Use semantic HTML
- Optimize every page for SEO
- Keep all content in Spanish
- Respect Bosón brand identity
- Use Inter and Open Sans typography
- Use colors from the brand manual
- Keep code production-ready

Deployment target:
cPanel shared hosting environment.

Contact form requirements:
- Secure implementation
- No exposed secrets
- Environment variables only
- Production-safe API usage

SEO requirements:
- Dynamic metadata
- Open Graph
- Sitemap
- Robots.txt
- Structured data
- Canonical URLs
- Proper heading hierarchy
- Semantic page structure

Performance requirements:
- Lighthouse 95+
- Fast image loading
- Minimal JS
- Lazy loading
- next/image usage

Important:
The uploaded PDFs and brand manual are the source of truth for:
- copywriting
- services
- brand tone
- mission
- vision
- visual identity
